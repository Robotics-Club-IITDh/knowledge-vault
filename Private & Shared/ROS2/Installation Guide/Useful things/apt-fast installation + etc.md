apt-fast is an external package made to increase download speed.
apt only downloads one file at a time.
apt-fast can download multiple, making the speed way faster.

Enter these commands into terminal. What does each command do?

```bash
sudo add-apt-repository ppa:apt-fast/stable
sudo apt update
sudo apt install apt-fast
```

A window should pop up allowing you to configure it. 
You’re done. Now anywhere you can substitute apt-fast for apt or apt-get and it will work.
