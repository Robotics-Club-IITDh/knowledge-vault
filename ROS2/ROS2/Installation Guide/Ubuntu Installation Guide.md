There are many ways of running Ubuntu - using a virtual machine, dual booting, etc

I recommend dual booting ( installing it on your computer alongside the operating system you have already - such as Windows ) so that you get the full and clean experience ( though linux is never clean when starting ) without breaking all the things you have on your normal system.

You can find several tutorials on how to do this online. It might be best to use one of them.
If you want to  follow my tutorial for installing ubuntu,
Here are the general steps to follow :

1 - **Download the Ubuntu ISO file
	I**t is a file which when put onto a USB (not copy pasted there) will run an Ubuntu based Ubuntu installer. You can download it from here
	[https://ubuntu.com/download/desktop](https://ubuntu.com/download/desktop)
2 - **Burn the ISO file onto a USB**
	[https://ubuntu.com/tutorials/create-a-usb-stick-on-windows#1-overview](https://ubuntu.com/tutorials/create-a-usb-stick-on-windows#1-overview)
3 - **Boot into your BIOS setting**
	This will vary for each laptop, so you need to find tutorials for this yourself, but here’s the general idea :
	Just search up BIOS in your windows settings, and choose an option. Your computer should restart and take you to a boot menu called your UEFI / BIOS, which is basically a very small operating system thats built into your motherboard by your computers hardware manufacturer.
	You should see something called the Boot Menu there.
	Select that and choose to boot from the USB onto which you have burnt Ubuntu.
4 - **Install**
	From here on, just follow the prompts on the screen. Read them all, and if theres any doubt then google it.

Abacadabra - you have installed Ubuntu
Hopefully.
